## 📌 Abstract
Contemporary data security paradigms operate on a fundamentally flawed premise: the **Fortified Vault Paradigm**, which assumes security is achieved by building stronger barriers around a known, centralized repository. 

**Oblivion Gate** introduces a paradigm shift from *vault fortification* to **vault elimination**. It decomposes sensitive data into semantically meaningless fragments, strips metadata, and distributes them across a permissioned network of nodes. It achieves security not just through cryptography, but through **Computational Infeasibility by Scale** and **Target Unlocatability**.

## 🚀 Core Innovations

1. **Zero-Trace Fragmentation (ZTF):**
   Information-theoretic fragmentation extending Shamir’s Secret Sharing with metadata elimination and ephemeral key architecture.

2. **Ballistic Decoy Saturation Protocol (BDSP):**
   Generates a "Network Supernova" by injecting 10,000+ cryptographically indistinguishable decoy capsules alongside the real payload. The adversary's advantage collapses to `1/N`.

3. **Synchronized Twin-Code Handshake Protocol (STCHP):**
   An ephemeral asymmetric authentication mechanism. Keys are generated and destroyed within volatile RAM during a single retrieval lifecycle. 

4. **Hardware-Stratified Cryptographic Purge Protocol (HS-CPP):**
   Concurrent, layer-specific hardware purging to eliminate forensic data remanence:
   * **SSD:** Cryptographic Erasure
   * **RAM:** 3-Pass Entropy Overwrite
   * **CPU Cache:** Saturation Flood

This repository contains two primary demonstration interfaces built to visualize and benchmark the theoretical frameworks:

* `Oblivion_Gate_BENCHMARK.html`: An academic evaluation dashboard providing interactive mathematical proofs (Probability of Attack Collapse), Attack Tree logical comparisons against classical cloud systems, and exact performance trade-off metrics.

## ⚙️ How to Run
The PoC interfaces are built using vanilla web technologies (HTML/CSS/JS) utilizing the native `window.crypto.subtle` API for true client-side cryptographic operations.
1. Clone the repository.
2. Open `Oblivion_Gate_DEMO.html` or `Oblivion_Gate_BENCHMARK.html` directly in any modern web browser.
3. No external servers or backend dependencies are required for the simulation.
